# Agent 产物归类方法（Codex / DSH 通用）

> 用途：把各 AI Agent（Codex / DSH，以及将来新增的 Agent）在工作区 / 用户根目录下**散落产生的脚本、临时文件、归档包**，
> 按 **Agent 名归类**，避免根目录与项目目录凌乱。
> 本方法对任何机器通用（家里 / 公司）；路径里的 `<用户主目录>` 换成你的实际用户目录即可。

---

## 一、目的

- 不把一次性脚本、临时归档堆到用户根目录或项目目录，保持《项目目录》干净。
- 任何人都能一眼看出某个文件是**哪个 Agent** 产生的、干什么用的、能不能删。
- 系统状态 / 配置目录不动，避免误删导致 Codex / DSH / OfficeCLI 等失效。

---

## 二、目录结构约定（统一收藏区）

```
<用户主目录>\_agents\
├── codex\        # Codex 产生的脚本 / 产物 / 归档包
├── dsh\          # DSH 产生的脚本 / 产物 / 归档包
├── <新Agent名>\  # 将来新增 Agent 时按其工具名再建同级目录
└── README.md     # 各 Agent 归档内容说明（当前归属）
```

- 新增 Agent：用其工具名建同名目录即可，互不干扰。
- 每个 `codex\` / `dsh\` 目录下可用一个子 README 标注来源与用途（可选）。

---

## 三、归类规则

1. **只归档"非运行占用、非系统状态"的散落产物**：一次性 py/ps1/sh 脚本、临时文本、中间结果、打包 zip、日志等。
2. **系统文件与 dot 状态目录一律原地不动**：
   - 系统文件：`NTUSER*`、`ntuser.dat*` 等；
   - dot 状态目录：`.codex\`、`.dsh\`、`.agents\`、`.officecli\`、`.cache\` 等。
3. **ACP 通信套件 `codex-acp-dsh\`** 属于 Codex↔DSH 的**公共通信层**，放在 `_agents` 之上，**不入** `codex` / `dsh` / 任何 Agent 分类。
4. **归属标注**：优先按**产生它的工具名**归到对应目录；归属不明的，先归 `dsh\` 并标注"待核"，有争议再人工确认。
5. **项目专用文件**：凡属于某个具体项目（如某采购/运维/研发项目目录）的资料，留在该项目目录内，不挪到 `_agents`。

---

## 四、遇到某类文件怎么处理（判定表）

| 文件/情况 | 归到哪 | 说明 |
|---|---|---|
| Codex 一次性脚本、临时归档、技能包 zip | `_agents\codex\` | 打 zip 也直接生成到 `_agents\codex\` |
| DSH 一次性脚本、临时归档 | `_agents\dsh\` | 同上 |
| 某项目的过程产物/草稿 | 对应**项目目录** | 不动，进项目文件夹 |
| ACP 通信套件 / 邮箱 / 桥接脚本 | `codex-acp-dsh\`（公共层） | 不归入任何 Agent |
| 系统文件（NTUSER* 等） | **原地不动** | 绝不移动/删除 |
| dot 状态目录（.codex/.dsh/.agents/.officecli/.cache 等） | **原地不动** | 仅供各自工具运行 |
| 根目录隐藏配置（.gitconfig/.node_repl_history/.pcr-stats.json 等） | **原地不动** | 属个人/工具配置 |
| 新产生、归属不明 | 先放 `dsh\` 并标注"待核" | 确认后移动/补说明 |

---

## 五、新机器 / 家里环境的落地步骤

1. 把整个 `_agents\` 目录（含本方法与 README）拷到新机器 `<用户主目录>\_agents\`。
2. 不需要新建 `codex\` / `dsh\` 时的初始化：放一份本方法与 `README.md` 即可，缺目录时按需自动建。
3. 告知两端 Agent（Codex / DSH）：把各自一次性产物放 `_agents\<Agent名>\`。
4. 若两端有固定的"打包/批处理输出目录"习惯，可在 `_agents\README.md` 里补充约定。

---

## 六、维护说明

- 每归档一批，顺手在 `_agents\README.md` 的"当前内容归属"里加一行来源与用途。
- 明确不再需要的归档，可告知对应用户后删除；系统 / dot 状态目录永不清理。
- 本方法与 `_agents\README.md` 分开：本方法是"归类规则/流程"，README 是"当前已归档内容清单"。
