# dsh-find 泰语（无空格文字）支持情况

> 起草于 2026-11-09，供社区回复用。原文作者可自行调整语气后发出。

---

## 一句话

**`dsh-find` 本来就能搜泰语，因为它是 DOM 子串匹配、不经过分词器。**
**0.2.0 把这个能力写进文档、加了回归测试、并补了桌面版实机验证。**

---

## 背景：问题出在哪

社区反馈（#1999）指出：`dsh-memory-plus` 的 CJK 分词没有覆盖泰语。

泰语这类文字**词与词之间没有空格**。`unicode61` 分词器会把

```
ช่วยวิเคราะห์คดีอาญานี้หน่อย
```

切成一堆碎片进 FTS 索引，于是直接查 **`คดีอาญา`**（「刑事案件」）时，
索引里根本没有这个词 —— **0 命中**。

这不是索引坏了，是**分词器的边界假设不成立**。

---

## 为什么 dsh-find 不受影响

```
dsh-memory-plus / memory-search    走 FTS5 + unicode61 分词 → 依赖词边界
dsh-find                           走 DOM 文本子串匹配      → 不需要分词
```

**⇒ 子串匹配不做任何切分，`คดีอาญา` 出现在哪就在哪高亮。**

**⇒ 所以这不是「我们特别支持了泰语」，而是**这条路天然不依赖分词**。**

---

## 本次改了什么（0.2.0）

| 改动 | 说明 |
|---|---|
| `lib/client.js` | 把匹配逻辑抽成**纯函数并导出**，可脱离 DOM 测试；补注释说明子串匹配不需要分词器 |
| `test/match.test.mjs` | 新增 3 个用例（零依赖，`node --test`） |
| `package.json` | 0.1.0 → 0.2.0；加 `test` 脚本；描述补「与泰语」 |
| `README.md` | 说明适用范围：**当前已加载会话**，不做跨会话检索、不动 FTS 索引 |

## 验证过程

### 一、单元测试（3/3）

```
✔ Thai: #1999 reproduction finds the word the FTS index misses
✔ Chinese: #8713 in-session find matches CJK keywords
✔ matching is case-insensitive and non-overlapping; empty query matches nothing
```

**⇒ 在 Linux 和 Windows（Node 24）上各跑一遍，均 3/3 通过。**

### 二、桌面版实机验证（DSH 0.2.2-rc.1）

在会话里让模型原样输出一句泰语：

```
ขนมจีนราดแกงกะทิไก่        （泰式米粉浇椰浆鸡）
```

然后按 `Ctrl+F` 搜索：

| 搜索词 | 是否在句中 | 结果 |
|---|---|---|
| `กะทิ`（椰浆） | 是，句中无词边界 | **1/2 命中**，两处都高亮 |
| `กุ้ง`（虾） | 否 | **0 条** |
| `อาชญากรรม`（犯罪） | 否 | **0 条** |

**⇒ 一个正例、两个反例。**

**⇒ 如果它「什么都匹配」，那 1/2 就没有意义 —— 反例证明它不会乱报。**

### 三、换句验证

补丁自带的测试句是 `ช่วยวิเคราะห์คดีอาญานี้หน่อย`；
实机验证用的是另一句 `ขนมจีนราดแกงกะทิไก่`。

**⇒ 换句子照样命中，说明是通用子串匹配，不是针对某个用例写死的。**

---

## 边界说明（顺便澄清 #8713）

社区那位提到：

> `/memory-search` 目前只搜当前会话，跨会话搜索仍在开发，
> 而且只返回匹配片段，没有高亮和跳转。

**这些说法是准确的，但说的是 `memory-search` 的能力边界。**

**⇒ `dsh-find` 是另一条路：**

```
dsh-find        当前已加载会话内查找，有高亮、有上/下一处跳转
memory-search   跨会话检索（开发中），返回片段，无高亮无跳转
```

**⇒ 两者是并列关系，不是同一个工具。**

**⇒ 我们也把这条边界写进了 README，避免被当成跨会话搜索使用。**

---

## 结论

```
问题：泰语在 FTS 分词器下搜不到
实情：这是分词器的边界假设问题，不是实现缺陷
现状：dsh-find 的路径不依赖分词，泰语本来就能搜
本次：把能力写清、加测试、补实机验证，避免类似反馈再出现
```

**⇒ 感谢社区指出这个问题 —— 它促使我们把一段「隐含行为」变成了「有测试保障的行为」。**
